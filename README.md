# hw-2

Написати веб-сервер (на модулі http) для завантаження великих файлів частками, передбачити інтерфейс списку завантажених файлів, просмотр файлу, видалення файлу,  статус виконання завантаження. Додати ліміт (квоту) на файлове сховище, тобто сумарно можна завантажити не більш ніж 3Мб файлів

## 📋 API Ендпоінти

### 🌐 Інтерфейс
* `GET /` — Головна сторінка (UI).

### 📂 Файли
* `GET /api/files` — Список усіх файлів.
* `GET /api/files/:fileName` — Перегляд або скачування файлу.
* `DELETE /api/files/:fileName` — Видалення файлу.

### 📤 Завантаження (Chunks)
1. **Init:** `POST /api/upload/init` — Початок завантаження (отримання ID).
2. **Chunk:** `POST /api/upload/chunk` — Передача частини файлу.
3. **Complete:** `POST /api/upload/complete` — Фінальна збірка файлу.
4. **Status:** `GET /api/upload/status` — Перевірка прогресу.

## 🔧 Встановлення та запуск

1.  **Клонуйте репозиторій:**
    ```bash
    git clone -b hw-2 https://github.com/nikitapotomkin/intership.git
    cd intership
    ```

2.  **Встановіть залежності:**
    ```bash
    npm install
    ```

3.  **Налаштування оточення:**

    ```env
    PORT =3000
    CHUNK_SIZE=258 
    REDIS_HOST='localhost'
    REDIS_PORT=6379 
    ```

4.  **Запустіть сервер:**
    ```bash
    npm run start
    ```

## 📖 Логіка завантаження частинами

1. Клієнт викликає `/api/upload/init`, щоб створити нову сесію.
2. Клієнт розбиває файл на частини і надсилає кожну частину на `/api/upload/chunk` разом із параметрами в URL.
3. Після відправки всіх частин викликається `/api/upload/complete`, що дає сигнал серверу об'єднати всі тимчасові чанки в один фінальний файл.
